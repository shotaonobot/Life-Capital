# Life Capital — プロダクト方針

更新：2026-09-15。ユーザーとの合意と、今回の実装範囲を記録する。

## 誰の、何を変えるか

大学生を最初の利用者として、自分のための時間が足りないと感じる人へ広げる。一か月後に、(1) 大切なことに使う時間が増える、(2) 無意識のSNS・動画の時間が減る、(3) 睡眠・休息・遊びを守れる、(4) 積み重ねを実感できる、の4つを目指す。

記録の量そのものを目的にしない。休息を浪費と決めつけない。毎回の開始・終了操作を必須にしない。ユーザーは夜のまとめ入力と任意タイマーを選び、間隔を設定できる通知を提案した。

## 中心体験

1. 日付・使い方・分数を選び、時間を加算。曜日別から合計値を直接修正できる。
2. 任意の声かけで記録を思い出す。30分〜4時間の間隔と時間帯を設定する。
3. 一週間を振り返り、来週の小さな行動を決める。数字の共有は本人の操作だけで行う。

「自分の時間がない」から「何に使ったか分かり、次に何をするか自分で選べる」へ。罰や罪悪感で継続させない。

## 要件と今回の実装

| 要件 | 実装 |
| --- | --- |
| 週168時間、投資20%以上・浪費5%以下・睡眠49h以上 | 固定分母168で即時判定。入力途中と完了を区別 |
| 曜日別の月〜日と日付 | 端末の現地日付。今日を薄赤色で表示。週送りと履歴 |
| 週合計は編集不可 | 読み取り専用で自動集計 |
| 入力を全選択 | 数値欄はタップ・フォーカスで選択 |
| 24時間超過 | 日カードを赤色、最後の欄を空欄に。25hが24hに丸められる旧不具合も修正 |
| 記録の継続 | 日付別の保存、旧データの移行、未入力から開始 |
| 素早い記録 | 15分・30分・1h・2h、任意分数、取り消し |
| 任意タイマー | 閉じても開始時刻保持。終了時、現地の深夜で日付分割して記録 |
| 声かけ | Webは画面表示中のみ。iOSはネイティブローカル通知のコードを実装 |
| 成長の実感 | 週の内訳、過去週、前週比較、短い振り返り、目標 |
| データ管理 | 端末内保存、JSONバックアップと復元、削除、共有、プライバシー説明 |
| iOS準備 | Capacitorプロジェクト、ネイティブ保存・通知・共有、Privacy Manifest |

旧版は曜日だけを保存していたため、実際の日付を完全には復元できない。最後に保存した週へ移し、そのことを利用者に知らせる。旧データは移行時に削除しない。バックアップの読み込みでは、重なる日付を上書きする前に確認する。

前週比較は両週の7日が24hずつ埋まった場合だけ表示する。未入力を改善・成長と誤認させない。20%・5%・49hはこのアプリで合意した基準で、個人への医学的な判定ではない。

## 市場調査と仮説

- [Forest](https://www.forestapp.cc/) は集中時間を木の成長で見せる。Life Capitalは計測を必須にせず、一日の生活全体と休息を含めて振り返ることを中心にする。
- [Studyplus](https://www.studyplus.jp/) は学習記録と仲間との交流を中心にする。Life Capitalは、勉強以外にも時間を取り戻したい人へ広げる仮説を検証する。
- [Structured](https://structured.app/) は予定の視覚化を中心にする。Life Capitalでは、実際にどう過ごしたかの簡単な記録から次の行動につなげる。

これらは機能の比較から立てた仮説で、利用者調査の結果ではない。ダウンロード数や市場シェアを根拠なく予測しない。100万ダウンロードは長期目標であり、保証できない。

## 次の検証

まず少人数の学生・忙しい社会人に7日間使ってもらい、入力の手間、分類の迷い、通知が邪魔な時間を確認する。招待はまだ送っていない。計測SDKは未導入で、本人の同意を得た聞き取りと任意の共有で検証できる。

検証指標：初日に1件記録できた割合、最初の記録までの操作数・時間、7日中の記録日数、通知を止めた理由、「大切な時間を確保できたか」の自己評価。数値目標は最初の実測を踏まえて決める。

咲太と次に決めること：達成時の動きと成長の見せ方。現版は落ち着いた紺・緑の道具として構成し、数値の変化を小さく動かす。キャラクター・物語・大きなアニメーションの最終案はまだ合意していない。

## 公開条件と残り

Web版は既存の公開Siteを更新する。iOS版はまだApp Storeへ提出していない。署名と配布にはApple Developerの登録と所有者の設定が必要。

Appleはアプリとしての十分な機能とプライバシー情報を求める。[App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/) を確認し、審査通過を保証しない。まず実機とTestFlightで通知、バックアップ、VoiceOver、文字拡大、長期間の保存を検証する。

料金・広告・課金、アカウント同期、ランキング、AI機能は今回追加しない。必要性を利用者の実測から判断する。
